# GVW Platform

The GVW Platform is a collection of software and hardware solutions designed to modernize choir organization, administration, and digital sheet music workflows.

The project aims to provide a connected ecosystem that simplifies everyday tasks for choir organizations while exploring dedicated solutions for digital music management.

## Projects

### GVW Office

GVW Office is a web-based organization management platform designed to support choir administration workflows.

Features include:

- Member management
- Document and content management
- Organization tools
- Administrative workflows
- Customizable interfaces

GVW Office is built with a modern web stack and focuses on providing a simple, efficient experience for everyday choir management.

### GVW Tablet

GVW Tablet is a dedicated digital sheet music platform designed to provide a focused alternative to traditional paper sheet music workflows.

The goal is to create a reliable device and software ecosystem optimized for musicians, including:

- Digital sheet music viewing
- Annotation capabilities
- A distraction-free experience
- Integration with the wider GVW ecosystem

## Technology

The GVW ecosystem uses a variety of technologies depending on the individual project:

- Web technologies for applications and interfaces
- Backend services and APIs
- Embedded and device development
- Custom software solutions

Each project contains its own technical documentation and setup instructions.
