# TB336FU Partition Layout

## Overview

The Lenovo TB336FU uses an Android A/B partition layout with dynamic partitions.
The device uses Android Verified Boot (AVB) and stores Android logical partitions
inside the `super` partition.

This document contains the currently identified partitions obtained from the running
Android system via ADB and block device inspection.

Physical partitions are exposed through:
```
/dev/block/by-name/
```

Logical partitions are exposed through:
```
/dev/block/mapper/
```
